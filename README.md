# 10-Spool-Tophat-for-Voron-2.4
This repo contains the model files, BOM, and everything else related to the design and implementation of a top hat for Voron 2.4 (and other printers) to support the Bondtech INDX

Alpha Release:

***Updated Panels, got mine in and the bottom one was a little tight and required slight modification for the joining plates. If you ordered the panels before this update, carefully use a dremel to remove the small piece enclosing each joining plate opening.***

This project is still in development, but I am releasing the fusion file publicly if anyone would like to contribute or fork it for other printers. Enjoy!

Use code:TOPHAT for 5% off your extrusions at Zyltech.com 

***1/10/26 update***, added files "200mm printed tophat.step" and "200mm printed tophat.f3z". These are a printed tophat spacer designed to add extra room for the bowden tubes. Included are front and back panels with holes for M3 heatset inserts and zip ties on the inside, and connector pieces to attach the panels together. You need 8 panels total, export them as you desire with or without the holes for the Creality Chamber Heater: https://www.amazon.com/dp/B0FJS593TQ
If you aren't using the Creality heater, just mirror one of the other front panel pieces in your slicer.
The following hardware is needed:

-M3x6 12pcs

-M3x16 12pcs

-M3 nut 12pcs

-M3 heat set insert 12 pcs

-M5x10 24pcs

-M5 roll in nut OR M5 T-nut 24pcs

-If using Creality heater, M3x8 3pcs

***Recommendations*** 

-Print in ABS or ASA

-Use a wide (10mm+) brim as these are very prone to warping

-No supports are needed

-Carefully remove the mouse ears after printing with a side cutter, do not try to bend them you will rip the bottom layer off the print

-Use 1mm foam tape between the pieces to seal them
